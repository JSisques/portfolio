# 24. English for technical artifacts

- Status: Accepted
- Date: 2026-11-26

## Context

The site targets both Spanish-speaking and international audiences (ADR-0003), and the repository itself is part of the showcase (`docs/vision.md`). Mixing languages across documentation is harder to read than either language alone.

## Decision

All technical artifacts are written in **English**: documentation, ADRs, code, identifiers, comments, commit messages, and pull request titles and descriptions.

User-facing site content is written in both Spanish and English (ADR-0003).

## Consequences

- International visitors inspecting the repository can follow every decision.
- Consistent with common industry convention and with commit messages read by release-please.
